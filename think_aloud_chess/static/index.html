Opções avançadas

O raciocínio do agente fica oculto durante a partida (jogo justo) e é liberado ao terminar — ou se você marcar "espiar".

Usar outro modelo via API (opcional)

A chave fica só em config.json no seu computador; não vai para partidas, arquivos exportados nem para o navegador. Modelos via API usam o mesmo fluxo (fatos, sondagem, validação), mas sem busca web e sem custo em US$ (só tokens).

Motor forte para a revisão do professor

Usado só depois da partida, pelo professor, para corrigir explicações com a verdade da posição. O Claude nunca o vê durante o jogo. Sem ele, a revisão usa a régua rasa (menos confiável).
