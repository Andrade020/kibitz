Kibitz - beta

Este programa roda no seu computador. Suas partidas e chaves de API ficam apenas na sua pasta de dados
(%LOCALAPPDATA%\Kibitz); nada é enviado a servidores do projeto.

Para o Claude jogar, o app usa o Claude Code (a sua conta do Claude) ou uma chave de API de outro provedor.
Na primeira abertura, uma tela de configuração guia você: instalar o Claude Code, entrar na conta ou colar uma chave.

Incluído neste instalador:
 - Stockfish 19 (GPLv3), usado apenas na revisão depois da partida. Código-fonte e licença:
   https://github.com/official-stockfish/Stockfish
 - Python, Flask (BSD-3), python-chess (GPL-3.0-or-later) e outras bibliotecas.

Kibitz é software livre sob a GNU GPL v3 ou posterior. Código-fonte:
https://github.com/Andrade020/kibitz

---
This program runs on your computer. Your games and API keys stay in your local data folder; nothing is sent
to any project server. To let Claude play, the app uses Claude Code (your Claude account) or another provider's
API key; a first-run screen guides you. Bundled: Stockfish 19 (GPLv3), Python, Flask, python-chess (GPL-3.0+).
Kibitz is free software under the GNU GPL v3 or later.
